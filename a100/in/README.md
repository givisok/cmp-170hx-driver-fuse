# Базовые версии для `mkpatches.py`

Генератор не строит патчи с нуля, а накладывает правки на эти два файла (на хосте они лежат
в `/root/a100-work/in/`):

| Файл | Что это |
|---|---|
| `sec2-good-backup.patch` | Рабочая версия `sec2-postbl-plm-ss-cfg.patch` до A100-блока: CMP-цикл с геометрией 80 GiB и закрытым гейтом для `0x20b5`. От неё генератор добавляет A100-блок и параметр `cmp_lmr`. |
| `booter-verify-upstream.patch` | `booter-verify.patch` из upstream v0.5 (коммит `17535a0`), байт-в-байт. От него генератор добавляет печать для `0x20b5`. |
